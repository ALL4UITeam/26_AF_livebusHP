# LIVEBUS 파티클 버스 데모

Vite + JavaScript(ES 모듈) + Three.js. 타입은 JSDoc 주석으로만 표기합니다. 흩어진 입자 약 6,000개(모바일 4,500개)가 약 3초 동안 모여 시내버스 한 대가 됩니다.

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (vite build)
```

- `src/busGeometry.js` — 버스 표면 좌표를 코드로 생성 (차체, 창틀, 앞문, 앞유리, 행선지 LED, 헤드라이트, 휠 아치, 타이어)
- `src/main.js` — 단일 `BufferGeometry` + `Points`, 시작→목표 보간, 카메라 자동 맞춤, 마우스 반발
- `src/logo.js` — 'LIVE BUS'를 캔버스에 그린 뒤 육각 격자로 샘플링한 점 글자 (차체와 같은 입자)
- 차체 전체 도색: 파랑 → 초록 → 빨강 (각 5초 유지 + 1초 전환). 넓은 패널은 중간 밝기, 모서리는 조금 밝게
- 조립 완료 → 0.45초 정지 → 전조등 '빵(0.12초), 빵(0.25초)' + 노면 빛 번짐 → 바퀴 회전 시작·5% 전진·차체 반동 → 상시등 주행
- 출발 직후 0.5초 동안 뒷바퀴 접지점에서 먼지, 이후 차선이 뒤로 흐름
- `src/drive.js` — 한 블록을 계속 도는 닫힌 코스: 직선 40 × 4 + 완만한 90° 좌회전(반지름 38, 완화곡선 8) × 4.
  차체 기준점(앞차축 바로 앞)이 차로 중심선을 따라가고 뒷차축은 끌려옴 → 뒷바퀴는 안쪽, 앞 범퍼는 바깥으로 돎.
  속도는 코스 위치의 함수(직선 8 → 코너 6.8)라 출발 이후 매 바퀴가 똑같이 반복되고 이음매에서 튀지 않음.
- 매 코너: 왼쪽 깜빡이 2회 → 완만한 감속 → 좌회전(앞바퀴 조향) → 조향 복귀·재가속. 조립과 전조등 '빵, 빵'은 최초 출발 때만
- 차로 경계선: 중심선에서 ±2.0 (차로 폭 4.0) 위치의 도로에 고정된 정적 점선, 각 선의 실제 길이 기준으로 일정 간격
- 카메라: 버스 위치를 따라가고 방향만 14 단위 늦게 따라감 → 코너에서 살짝 늦게 돌며 안팎 차선이 함께 보임
- 검증용 시점: `?view=top` (코스 전체), `?view=top&follow` (버스 위에서), `&speed=4` (빠르게 재생)
- `R` 키를 누르면 위치·조향·깜빡이·카메라까지 처음부터 다시 재생합니다.
